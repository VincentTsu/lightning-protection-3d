# GB50064 防雷计算可视化工具 — 设计规格

## 概述

基于 GB50064 折线法（保护角法）的防雷保护范围 3D 可视化工具。在三维空间中布置避雷针、避雷线、设备，实时计算并展示保护范围包络面，直观判断设备是否受保护。

## 计算引擎 — GB50064 折线法

### 高度修正系数

```
p = 1          (h ≤ 30m)
p = 5.5 / √h  (30m < h ≤ 120m)
```

### 避雷针

**单针保护半径** （地面以上 hx 高度处）：

```
hx ≥ h/2  →  rx = (h − hx) × p
hx < h/2  →  rx = (1.5h − 2hx) × p
```

- 地面保护半径：r0 = 1.5h × p
- ha = h − hx（有效高度）

**双针联合保护**：
- 联合保护范围最低点高度：h0 = h − D/(7p)
- D 为两针间距
- 两针之间保护范围：以 h0 为顶点、两针为底的圆弧过渡

**多针联合保护**（≥3 根）：
- 相邻三针构成的三角形区域，若任意两针间距 D ≤ 7·ha·p，则三角形内部全部受保护
- 取最不利的两针对计算 h0

### 避雷线

**单线保护宽度** （地面以上 hx 高度处）：

```
hx ≥ h/2  →  bx = 0.47(h − hx) × p
hx < h/2  →  bx = (h − 1.53hx) × p
```

- 地面保护宽度：b0 = h × p

**双线联合保护**：
- 联合保护最低点：h0 = h − D/(5p)（近似）

### 设备保护判定

设备位置 (x, y, hx) 判断是否在任意避雷针或避雷线的保护范围内：

1. 单针：设备投影距离 ≤ 该针在该高度的保护半径 rx → 受保护
2. 单线：设备到线的垂直投影距离 ≤ 该线在该高度的保护宽度 bx → 受保护
3. 多针/多线联合区域：设备投影在联合保护区域内 → 受保护

## 数据模型

```typescript
interface LightningRod {
  id: string;
  x: number;       // 地面坐标 X (m)
  y: number;       // 地面坐标 Y (m)
  height: number;  // 针高 h (m)
  type: 'rod';
}

interface LightningWire {
  id: string;
  x1: number; y1: number;  // 起点地面坐标
  x2: number; y2: number;  // 终点地面坐标
  height: number;          // 线高 h (m)
  type: 'wire';
}

interface Equipment {
  id: string;
  x: number; y: number;    // 地面坐标
  height: number;          // 设备高度 hx (m)
  width: number;           // X 方向尺寸 (m)
  depth: number;           // Y 方向尺寸 (m)
  label: string;           // 设备名称
}

interface ProtectionStatus {
  equipmentId: string;
  protected: boolean;
  protectedBy: string[];   // 保护来源（针/线 ID 列表）
  margin: number;          // 保护裕度 (m)
}
```

## 3D 场景设计

### 场景元素

| 元素 | 3D 实现 | 说明 |
|------|---------|------|
| 地面 | `PlaneGeometry` + `GridHelper` | 浅灰平面，10m 主网格 + 1m 次网格 |
| 避雷针 | `CylinderGeometry` + `SphereGeometry` | 细圆柱 + 尖端球体，暗红色 |
| 避雷线 | `TubeGeometry` 或 `Line` | 两点之间的悬挂线，深青色 |
| 设备 | `BoxGeometry` | 紫色立方体，未保护时红色描边 |
| 保护包络 | 自建 `BufferGeometry` | 半透明圆锥/三棱柱组合面 |
| 尺寸标注 | `Line` + `Text` (drei) | 虚线 + 文字标签，黑色/深灰 |
| 相机 | `PerspectiveCamera` + `OrbitControls` | 默认 45° 俯视角，可旋转/缩放/平移 |

### 保护包络面生成

**避雷针包络**（分段圆锥台）：
1. 上半段（h → h/2）：以针尖为顶点，母线斜率 = 1/p（即半径 r = (h − hz)·p）
2. 下半段（h/2 → 0）：半径 r = (1.5h − 2hz)·p
3. 沿高度方向采样 N 个截面圆，构建环形 Mesh

**双针联合包络**：
1. 分别生成两针的独立包络
2. 在两针之间，以 h0 为最低点生成圆弧过渡面（椭圆弧）
3. 合并生成联合包络 Mesh

**避雷线包络**：
1. 沿线方向：生成三棱柱（上顶点在线上，下底在地面）
2. 两端：半圆锥盖
3. 保护宽度 bx 随高度 hx 变化

### 相机默认位置

- 初始视角：俯视 45°，方位角 −30°
- 目标点：场景中心
- 缩放范围：5m ~ 500m

### 参数面板功能

- **避雷针列表**：显示每根针的 ID、高度、保护半径。展开后可编辑 x、y、h。支持添加/删除
- **避雷线列表**：显示每条线的 ID、高度、长度。展开后可编辑起终点、h。支持添加/删除
- **设备列表**：显示每个设备的 ID、高度、保护状态（绿色✓/红色✗）。展开后可编辑 x、y、hx、尺寸
- **关键尺寸区**：自动汇总显示 r0、D、h0、保护裕度等
- **导出按钮**：一键导出当前 3D 视图为 PNG

## 验证标准

1. **公式正确性**：手工计算一个案例（1针1设备），与软件计算结果对比
2. **3D 渲染**：场景可旋转/缩放/平移，元件位置与参数面板数据一致
3. **实时更新**：修改高度参数后，包络面和标注线实时刷新
4. **保护判定**：设备移到保护范围内外，面板状态正确切换 ✓/✗
5. **截图导出**：点击导出按钮，下载的 PNG 与当前视图一致
6. **多针/多线**：≥3 根避雷针时联合保护范围正确显示
